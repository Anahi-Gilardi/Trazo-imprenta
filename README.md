# TRAZO Espacio Gráfico (@trazo.grafica)

Sitio web oficial, tienda online y panel de administración para **TRAZO Espacio Gráfico** (Río Cuarto, Córdoba, Argentina).

## Características principales

- **Catálogo de Productos Dinámico:** Filtrado por categorías, buscador en tiempo real, ordenamiento por precio y carrito de compras lateral.
- **Integración con Mercado Pago y WhatsApp:** Checkout preparado para links de pago, transferencia por alias o SDK oficial de Mercado Pago V2, además de envío directo del pedido por WhatsApp (`+54 9 358 510-4732`).
- **Panel de Administración Privado:**
  - Acceso mediante el botón `Administración` en el pie de página, 3 clics sobre el logo `TRAZO`, atajo `Alt + A` o agregando `#admin` a la URL.
  - Creación, edición y eliminación de **productos** (con subida de imágenes optimizadas) y **categorías**.
- **Diseño 100% Adaptable (Responsive):** Optimizado para celulares Android, iOS (iPhone), tablets y escritorio.
